01 / 06Backend · Distributed Systems

Distributed Rate Limiter

Rate limiting that stays correct when multiple server instances share one view of traffic.

  • Redis-backed request tracking, atomic via Lua scripts
  • Fixed Window Counter, IP-based, as middleware
  • 429 when limit exceeded; 503 when Redis is down
  • Docker Redis, load tested with Artillery across multiple instances
  • Configured: 5 requests / 60 s
